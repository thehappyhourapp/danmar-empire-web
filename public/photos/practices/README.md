One 16:10 frame in the opening row of each practice page and /relocating (`<route-slug>.jpg` at the source's width, 1536, and `<route-slug>-800.jpg`), plus a second frame where the page has a natural place for one (`<route-slug>-2.jpg`, `<route-slug>-2-800.jpg`).
